# كاميرا FTTH الميدانية

تطبيق أندرويد (Kotlin + CameraX) لفنيي صيانة الكيبل الضوئي: وضع داكن، واجهة عربية، علامة مائية بالإحداثيات.

## طريقة الحصول على ملف APK

### الطريقة 1: Android Studio (الأسهل)
1. افتح Android Studio ثم **File > Open** واختر هذا المجلد.
2. انتظر انتهاء Gradle Sync (يحتاج إنترنت أول مرة).
3. من القائمة: **Build > Build APK(s)** ثم اضغط Locate.
   لإصدار محسّن وأسرع: **Build > Generate Signed App Bundle / APK > APK**.

### الطريقة 2: GitHub Actions (بدون تثبيت أي شيء)
1. أنشئ مستودعاً جديداً على GitHub وارفع محتويات هذا المجلد كما هي.
2. ادخل تبويب **Actions** ثم **Build APK** ثم **Run workflow**.
3. بعد دقائق نزّل `FTTH-Field-Camera-APK` من قسم Artifacts، وفيه الملف `app-release.apk`.

> ملاحظة: يُنشأ مفتاح التوقيع من جديد في كل تشغيل، لذلك عند تحديث التطبيق فوق نسخة قديمة
> قد يطلب أندرويد حذف النسخة القديمة أولاً. لتوقيع ثابت أنشئ مفتاحك مرة واحدة
> وضعه في `app/release.jks` (كلمة المرور والاسم المستعار كما في `app/build.gradle`).

### الطريقة 3: سطر الأوامر
```
gradle assembleRelease      # يحتاج Gradle 8.7+ وJDK 17 وAndroid SDK 34
```
الناتج: `app/build/outputs/apk/release/app-release.apk`

## الميزات
- كاميرا بملء الشاشة، أمامية وخلفية، لمس للتركيز وقرص للتكبير.
- مصباح ذكي: مغلق ← مستمر ← عند التصوير فقط.
- زوم سريع 1x / 2x / 3x وزر منع التوهج (يخفض التعريض لقراءة شاشات Power Meter والمودم).
- 5 قوالب للعلامة المائية، تُحفظ الصورة في `Pictures/FTTH-Camera`.
- حقلا FAT وZONE يُحفظان بين الجلسات ويُطبعان على الصورة.
- العلامة المائية: العنوان (Geocoding)، الإحداثيات، الاتجاه (Azimuth) مع بوصلة، التاريخ والوقت.
- تُكتب البيانات أيضاً داخل EXIF (الموقع، الاتجاه، FAT/ZONE) ليقرأها قارئ المعرض.
- قارئ المعرض: اختيار صورة، قراءة الإحداثيات والتاريخ والوقت، وزر «الذهاب للموقع» يفتح ملاحة Google Maps.
- القائمة: من نحن (فيسبوك)، حول التطبيق، خروج.
